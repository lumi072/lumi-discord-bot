# Lumi Discord Bot 🌙

Lumi는 개인용 Discord 음악/대화 봇입니다.

## 주요 기능
- Discord 음악 재생
- MusicWidget 원격 제어
- AI 대화
- 호감도 시스템
- 미니게임
- 끝말잇기

## 우리말샘 Open API 사용 목적
우리말샘 Open API는 끝말잇기 미니게임에서
사용자가 입력한 한국어 단어가 실제 사전에 존재하는지 확인하고,
루미가 이어갈 수 있는 단어를 찾는 용도로 사용합니다.

개인용 Discord 서버에서 사용합니다.
